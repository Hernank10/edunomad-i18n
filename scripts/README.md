# Scripts de utilidad

Scripts de un solo uso para poblar/administrar la base de datos de EduNomad.

## Uso

Desde la raíz del proyecto:

    E:\pydj5.bat scripts\<script>.py

## Contenido

- `crear_*.py` — crear registros masivos (cursos, certificados, evaluaciones...).
- `generar_*.py` / `generar_*.sh` — generar contenido pedagógico.
- `importar_*.py` — importar recursos desde archivos externos.
- `gestion_roles*.py` — gestión de roles de usuario.
- `registrar_estudiantes_masivos.py` — alta masiva de estudiantes.
- `sincronizar_cursos.py` — sincronización de cursos.
- `verificar_*.py` — scripts de verificación de datos.
- `arrancar.bat` — launcher alternativo.
- `estudiantes_template.csv` — plantilla CSV para importar estudiantes.
